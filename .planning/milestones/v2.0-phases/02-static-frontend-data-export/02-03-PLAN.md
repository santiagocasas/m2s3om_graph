## Trust Boundaries

| Boundary | Description |
|----------|-------------|

| Rendered rule strings → DOM | Text content injected into `<td>` cells; XSS possible if `escapeHtml` bypassed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06 | Injection (XSS) | `renderRules` DOM writes | medium | mitigate | Task 1 preserves the scaffold's `escapeHtml()` helper and uses it for every dynamic string interpolation (`source_display`, `target_display`, `mapping_type`, `strategy`, all row content). The strategy badge className uses only values from a controlled enum (`deterministic|llm|fallback`), so no attacker-controlled class injection. |
| T-02-03 | Tampering | SurrealDB record IDs at runtime | medium | mitigate | Task 2 `escapeId()` backtick-wraps any non-alphanumeric ID; combined with plan-02's build-time `validate_id`, provides defense-in-depth. |
| T-02-07 | Information Disclosure | Error message reveals server-side path | low | accept | The fail-closed copy names `public/data/crosswalk_graph.json` — this is a build-time artifact path, not a server path, and the entire site is public GitLab Pages. Path disclosure has no confidentiality impact. Rationale: UI-SPEC prescriptively requires this copy for developer guidance. |
</threat_model>
