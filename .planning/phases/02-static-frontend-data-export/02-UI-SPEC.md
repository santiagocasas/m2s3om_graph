## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f7f5ef` (--bg) | Page background |
| Secondary (30%) | `#fffdf8` (--panel) | Cards, table background, form controls |
| Accent (10%) | `#d06f32` (--accent) | Left border on callouts, selected state indicator, eyebrow text |
| Destructive | `#a33a3a` (--bad) | Rules with semantic_loss flag, failed-load errors |

**Accent reserved for:**
- `.callout` left-border
- `.eyebrow` label text
- Navigation link hover underline accent on brand background
- **Never used for:** buttons, badges (use `--brand` for badges), or rule type chips

**Semantic color usage:**
- `.good` / `--good` (`#2f7d57`): rules with confidence ≥ 0.9
- `.warn` / `--warn` (`#b35a1f`): rules with ambiguity flag, semantic loss display
- `.bad` / `--bad` (`#a33a3a`): rules with semantic_loss flag, fetch errors

## Additional Design Contract

### SurrealDB ID Escaping

Crosswalk IDs with dashes (e.g. `rdamsc-c5`) are invalid SurrealQL record IDs without escaping.
Add to `src/graph-loader.js`:

```javascript
function escapeId(raw) {
  return /[^a-zA-Z0-9_]/.test(raw) ? `\`${raw}\`` : raw;
}
// Use: await db.create(`crosswalk:${escapeId(crosswalk.id)}`, {...});
```

### Strategy Badge Colors

Display `strategy` (deterministic/llm/fallback) as a color-coded inline badge:

| Strategy | Badge Style |
|----------|-------------|
| `deterministic` | `background: #e9eff5; color: var(--brand-dark)` (default badge) |
| `llm` | `background: #f5f0e9; color: #7a5c2e` (warm amber tint) |
| `fallback` | `background: #f9e9e9; color: var(--bad)` (red tint) |

Add to `src/style.css` and render in rules table `<td>`.

### Table Column Order

Final rules table columns (updated from scaffold original):

| Column | Source | Notes |
|--------|--------|-------|
| Source field | `rule.source_path` (single string) | First cell |
| Target field | `rule.target_paths.join(', ')` or `<em>missing</em>` | Second cell; missing uses `.warn` color |
| Mapping type | `rule.mapping_type` | Third cell |
| Confidence | `rule.confidence.toFixed(2)` | Fourth cell; green ≥ 0.9, default otherwise |
| Strategy | `rule.strategy` badge | Fifth cell; color-coded per table above |
| Semantic loss | `rule.semantic_loss ? "⚠" : ""` | Sixth cell; icon only, `.bad` color; must include `aria-label="semantic loss detected"` on the icon element (empty cells omit the attribute) |
