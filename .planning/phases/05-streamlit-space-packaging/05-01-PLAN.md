| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-01 | Information Disclosure | SurrealDB credentials in Space image | high | mitigate | `build_default_store()` reads credentials from env only (D-04); Dockerfile bakes no secrets; guard test in Task 2 fails on any hardcoded non-env SurrealDB URL. |

| T-05-04 | Denial of Service | Cold-start / unbounded dep install | low | accept | Free-tier HF Spaces sleep after inactivity; documented as known limitation. Pinned requirements.txt (D-03) bounds install determinism. |
