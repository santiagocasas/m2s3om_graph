<objective>
Replace uppercased internal-ID dropdown labels with canonical standard names sourced from the SSSOM `mapping_set_description` header, surface the acronym expansion as a subtitle under the dynamic heading, and propagate the same canonical crosswalk name into the graph page's edge labels — reusing the existing description-parsing logic instead of inventing frontend strings.

Purpose: After 260827-gnm, the dropdown now reads `RDAMSC_C32 → DST_RDAMSC_C32 (rdamsc_c32)` — that surfaces internal IDs as primary UI. The catalog already carries canonical names ("ABCD (Access to Biological Collection Data) → Darwin Core") inside the SSSOM description parenthetical; the explorer just isn't using them. This plan pipes those canonical names through the export layer into the dropdown, the heading, the subtitle, and the graph edges — so the explorer and the graph page speak the same domain vocabulary the researchers use.

Output: Updated exporter that emits `source_acronym`, `source_expansion`, `target_acronym`, `target_expansion` per crosswalk; updated `main.js`/`index.html`/`style.css` that render those fields as label + heading + subtitle; updated graph-JSON producer that reuses the same parser for edge labels; regenerated `web/data/crosswalk_graph.json` and `web/data/graph/crosswalk_graph.json`; test coverage for the new fields and UI wiring.
</objective>
